# 床・ドア/カラーセレクト

マンション販売の現場で、**床7種 × ドア7種＝49通り**の組み合わせを、その場で完成イメージにして見せるアプリです。
営業担当者がタブレットで床とドアの写真を押すと完成イメージが切り替わり、気に入った組み合わせをA4の紙やPDFでお客様にお渡しできます。

Claude Code を使って制作しました。物件名「（仮称）NAHAレジデンス」、品番（FL-01〜07、DR-01〜07）、見本のお客様は、すべて架空のものです。

## 審査の方へ：画像について

このリポジトリには**プログラムだけ**を入れ、**画像は入れていません**。
完成イメージや素材の写真にメーカーの素材が含まれており、誰でも見られる場所への公開を控えたためです。

そのため、このままアプリを開くと、画像の部分は表示されません。
**画像が入った実際の動きは、応募フォームで提出した動画をご覧ください。**

## できること

- 床とドアの写真を押して、完成イメージと名前・品番を切り替える
- 表示中の組み合わせをA4縦で印刷する（お名前などが空欄なら手書き用の線が入る）
- 印刷と同じ内容をPDFにして、文章入りのメールを作る
- 同意を得たお客様の、来場日と見た組み合わせを記録し、再来場のときに呼び出す（暗証番号つき。記録はそのブラウザの中だけに残る）

## しくみ

- 床＋インテリアの画像（JPG）の上に、背景が透明で同じ大きさのドアの画像（PNG）を重ねて表示します。**14枚の画像で49通り**を表現しています。
- HTML・CSS・JavaScript の1ファイルだけでできています。ライブラリやサーバーは使わず、ダブルクリックで開けて、インターネットなしで動きます（「Gmail で開く」を除く）。
- 床・ドアの名前や品番、物件名、印刷の注意書き、メールの文章は、html の上の方にある `SETTINGS` を書き換えると変えられます。
